APK 静态检查摘要

- APK 很薄：核心业务基本都在 assets/index.html。
- classes.dex 主要提供：
  - WebView
  - Android ID 读取
  - SharedPreferences 本地存储桥
  - Android 返回/退出桥
- 未发现业务网络请求（fetch/XMLHttpRequest/WebSocket）。
- 现有卡密校验：
  - RSA-SHA256 / RSASSA-PKCS1-v1_5
  - 公钥内置于 HTML
  - 卡密格式 TC2
  - 设备码 24 位十六进制
- 原 APK 当前启动脚本存在无条件 unlockLicensedApp()，因此卡密实际上被直接绕过；PWA v1 已修复。
- 主要功能页均为 Web HTML/CSS/JS：
  - 首页
  - 请销假
  - 请假申请
  - 请假记录
  - 请假详情
  - 学校名称自定义
  - 使用须知 / 更新公告 / 关于与支持
- 因此 UI 和现有本地业务功能适合迁移为 PWA。
